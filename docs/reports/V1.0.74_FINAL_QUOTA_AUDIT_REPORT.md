## 5. Shared Admission Gate

**SOURCE CODE EVIDENCE:**

- **Shared Mutex**: `ManualServerAdmission.kt:107-108` — process-wide static `lock = Mutex()`, shared by every instance
- **Count inside critical section**: `ManualServerAdmission.kt:65-84` — `admit()` reads `count()` inside `lock.withLock`, computes `remaining = quota - current`, grants `allowance = minOf(want, remaining)`
- **Room + JSON covered**: `ManualServerAdmission.kt:158-165` — `productionManualServerRecordCount()` sums `manual_server` rows + JSON imported rows
- **New records limited**: `ManualServerAdmission.kt:77` — `allowance = minOf(want, remaining)`; `ManualImportStore.kt:116-119` — new rows only stored if `slots > 0`
- **Updates consume no slot**: `ManualServerAdmission.kt:77` — `if (want == 0) 0`; `ManualServerStore.kt:109-114` — duplicate lookup inside critical section returns `requested = 0` for existing keys
- **Duplicate imports consume no slot**: `ManualImportStore.kt:114-115` — `current.containsKey(key)` → `updated++`, no slot consumed
- **Rejected additions leave no partial record**: `ManualServerStore.kt:119` — `if (existing == null && allowance <= 0) return@admit false`; test `H a rejected addition leaves no partial record`
- **Concurrent additions cannot exceed quota**: `ManualServerAdmission.kt:107-108` shared Mutex; test `H concurrent additions cannot exceed the quota`
- **Over-cap edit/delete preserved**: `ManualServerAdmission.kt:32-36`; test `G an over-cap user can still edit and delete`, `G data already over the quota is preserved and cannot get worse`
- **Total-retention policy preserved**: `ServerListUpdates.kt:564-566` — manual/imported rows never pruned; `capRetainedServers()` trims only network rows
