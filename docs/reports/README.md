# Phase Reports Archive

This folder holds the project's phase reports, audits, and verification records, moved out of the
repository root on **2026-10-18** to keep the root limited to the canonical documents.

- Canonical documents remain at the repository root: [`README.md`](../../README.md),
  [`PROJECT_SPECIFICATION.md`](../../PROJECT_SPECIFICATION.md),
  [`SERVER_SOURCE_ARCHITECTURE.md`](../../SERVER_SOURCE_ARCHITECTURE.md), and
  [`AGENTS.md`](../../AGENTS.md).
- **Filenames are unchanged.** References inside the specification and architecture document use
  bare filenames (for example `SERVER_UPDATE_VPN_FALLBACK_REPORT.md`), so they still resolve by name
  to the files in this folder.
- Nothing was deleted. Reports that were previously untracked were committed here so they remain
  part of the project history.
- Reports are point-in-time evidence: a report describes the tree at its own HEAD, not the current
  one. Do not treat a report as current behavior without checking the specification.
